## Now

**Writing** — [harness-ablation](https://github.com/Xabilimon1/harness-ablation): an empirical ablation study of LLM agent-harness components (prompt structure, tool selection, retry policy, context management, error handling). Extends Anthropic's *Quantifying infrastructure noise in agentic coding evals* outward — if infra config dominates eval variance, what does the rest of the harness do? Paper in progress.

**Studying** — the [ARENA](https://www.arena.education/) alignment curriculum, plus the original mech-interp experiments I run alongside each chapter ([solutions repo](https://github.com/Xabilimon1/xabier-arena-solutions)).

**Contributing** — merged fixes into the eval infrastructure behind frontier-model safety research: [METR/hawk](https://github.com/METR/hawk/pull/627), [Princeton HAL](https://github.com/princeton-pli/hal-harness/pull/182), and [ECC](https://github.com/affaan-m/ECC/pull/920).

**Writing in public** — [xabier.me](https://xabier.me): a research notebook on evals, mech interp, agent harnesses, and the production lessons that pushed me here.

## Merged contributions

Fixes to the eval infrastructure behind frontier-model safety research.

- **[METR/hawk #627](https://github.com/METR/hawk/pull/627)** — [METR](https://github.com/METR) (Model Evaluation & Threat Research). Auth fix in `hawk`, their cloud Inspect-AI eval runner: a passthrough credential header containing only whitespace is now treated as missing (`401` + `anonymous`) instead of surfacing an unactionable `"invalid api key"`. *Merged.*
- **[princeton-pli/hal-harness #182](https://github.com/princeton-pli/hal-harness/pull/182)** — [HAL](https://github.com/princeton-pli), the Holistic Agent Leaderboard (Princeton PLI). Resolved a `wandb`/`weave`/`gql` version conflict that broke every agent-env container at startup; aligned the three runners, the Docker image, packaging, and contributor docs. *Merged.*
- **[affaan-m/ECC #920](https://github.com/affaan-m/ECC/pull/920)** — [everything-claude-code](https://github.com/affaan-m/ECC). Contributed the Token Budget Advisor skill. *Merged.*
